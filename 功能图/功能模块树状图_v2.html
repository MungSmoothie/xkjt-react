网站版 · 设备码权限体系 · 直播+AI预留
📅 2026.03.26 👨‍💻 村口情报社 · 二狗 ⏱ 开发周期 10-14 周 💰 启动成本 ¥600-1000/月（不含人力）
  • ▼一、用户与账户体系 P1 核心根基
    • ▼1.1 角色与权限等级
      • 游客（未登录）→ 只能看免费内容
      • 普通用户（已登录，无设备）→ 免费 + 可付费购买单课
      • 超声绑定用户 → 解锁超声全部付费课
      • 智能笼绑定用户 → 解锁智能笼全部付费课
      • 双设备用户 → 同时解锁超声 + 智能笼全部课程
    • ▼1.2 注册流程
      • 手机号 + 验证码（60秒防刷，5分钟有效）
      • 密码设置（6-20位，数字+字母）
      • 设备码输入 → 后台校验有效性 → 识别设备类型（US/IC/MX）
      • 设备码状态分支：未绑定/已绑定其他账号/已过期/解绑中
      • 协议勾选（隐私政策+用户协议+医疗免责）
      • 推荐：微信扫码输入设备码，体验零门槛
    • ▼1.3 登录流程
      • 手机号 + 密码，或手机号 + 验证码
      • 密码错误3次 → 图形验证码；连续5次 → 锁定30分钟
      • 登录后合并所有已绑定设备类型 → 计算课程权限列表
      • 记录设备指纹 → 异常IP多账号关联告警
    • ▼1.4 账户功能
      • 个人主页（头像/昵称/认证标识）
      • 学习档案（学习时长/课程进度/证书）
      • 消息中心（系统通知/课程更新/直播提醒）
      • 通知设置（邮件订阅/短信/推送偏好）
  • ▼二、设备码与权限管理 核心护城河
    • ▼2.1 设备码编码设计
      • 格式：产品前缀(2位) + 批次号(4位) + 随机序列号(6位) + 校验位(1位)
      • 示例：US-2026-384721-3 / IC-2026-XXXXXX-X / MX-2026-XXXXXX-X
      • 校验位：前12位数字取模97，100减去余数（ISO 7064 MOD 97-10，防伪造）
      • 前缀：US=超声系列，IC=智能笼系列，MX=混合系列（同时解锁US+IC）
    • ▼2.2 多设备绑定规则
      • 一账号可绑定多台不同类型设备，权限叠加
      • 同一类型设备不可重复绑定（报错"该类型设备已绑定"）
      • 最多绑定 3 台设备（不论类型）
    • ▼2.3 解绑流程（必须审核）
      • 用户申请 → 填写原因（设备损坏/换机/不再使用/其他）
      • 提交后设备码状态变为"解绑中"（此时不可用）
      • 后台管理员审核（查看原因 + 历史学习记录）
      • 拒绝 → 恢复设备绑定；通过 → 设备码恢复"未绑定"
      • 审核结果邮件/短信通知用户
    • ▼2.4 权限矩阵
      • 游客：免费科普/试听课/直播预告
      • 普通用户：免费内容 + 💰 付费购买单课/专栏
      • 超声绑定：超声全部付费课/直播/文档（无需额外购买）
      • 智能笼绑定：智能笼全部付费课/直播/文档（无需额外购买）
      • AI智能问答：双设备用户均可用（设备码绑定后解锁）
  • ▼三、课程内容系统 用户留存根本
    • ▼3.1 课程管理
      • 按学科分类：超声基础 / 超声临床（腹部/心超/妇产/小动物）/ 智能笼系统 / 影像诊断 / 设备维护
      • 按级别：⭐入门（学生/新手工程师）/ ⭐⭐进阶（技师/住院医）/ ⭐⭐⭐高阶（主治/资深工程师）
      • 按形式：🎬视频课（主，占比60%）/ 📄图文课 / 🔴直播课 / 🎧音频课
      • 课程单元结构：课程→章节→课时→知识点
      • 课程上下架管理 / 批量导入
    • ▼3.2 视频播放器（Video.js / DPlayer）
      • HLS/DASH 自适应码流（480p/720p/1080p）
      • 倍速播放（0.5x~2.0x）/ 断点续播 / 记忆播放位置
      • DRM 加密播放（防下载）防盗
      • 跑马灯水印叠加（用户ID+时间戳，防录屏）防盗
      • 每30秒进度保存 / 章节列表跳转 / 讲义PDF预览
      • 章节答题解锁：每10分钟答对1道题才能继续，防打断连续录屏
    • ▼3.3 视频防盗体系 高风险
      • Layer 1 — DRM加密：VOD HLS CMAF，浏览器端解密，源文件不可直接下载
      • Layer 2 — URL签名：CDN Key 签名，GET参数时效签名（默认1小时）
      • Layer 3 — Referer黑名单：禁止常见视频网站嵌入
      • Layer 4 — 跑马灯水印：切片时嵌入动态水印
      • Layer 5 — 章节答题解锁：打断连续录屏
      • Layer 6 — IP+UA限制：同一账号最多2设备同时播放
    • ▼3.4 学习工具
      • 收藏/历史记录
      • 课程搜索（标题/标签/学科）
      • 文档全文搜索（PDF在线预览）
      • 学习路径（体系课完整路径 / 单课购买）
      • 学习计划（自定义周期目标）
  • ▼四、直播培训系统 差异化竞争
    • ▼4.1 直播类型
      • 公开直播：免费观看，预约制，有回放（产品发布会/公开课/学术讲座）
      • 专业直播：设备码绑定用户专属，有回放（内部培训/高阶课程/实操演示）
      • 付费直播：单独购票，限时回放（专题研修班/认证课程）
    • ▼4.2 技术链路
      • 讲师推流：OBS Studio / 腾讯云直播控制台（网页推流）→ RTMP over SSL
      • 推流参数：1080p / 720p，30fps，2500-4000kbps，AAC-LC 128kbps
      • 腾讯云 CSS：实时转码（多码率）/ 截图鉴黄 / 自动录制MP4 / 敏感词过滤
      • 观众端：flv.js（推荐，延迟3-5秒）/ HLS.js（兼容性，5-10秒）/ DPlayer
      • 自动降级：flv → hls → mp4（根据浏览器支持）
    • ▼4.3 直播功能清单
      • 直播预约 → 开播前邮件/短信/Web Push提醒 必须
      • 实时观看 + 弹幕/聊天（WebSocket或腾讯云IM）必须
      • 禁言/踢人（管理员操作）必须
      • 直播回放自动生成（CSS→VOD）必须
      • 回放点播（复用点播播放器）必须
      • 直播答题（WebSocket广播题目→统计→结果）重要
      • 直播公告（跑马灯推送）重要
      • 直播数据统计（观看人数/峰值/时长/弹幕数）重要
      • 回放剪辑（云函数API触发）重要
      • 连麦互动（WebRTC/TRTC）可选
    • ▼4.4 直播间页面结构
      • 顶部：直播标题 · 讲师信息 · 状态（预告/直播中/已结束）
      • 左侧：视频播放器（flv.js）— 弹幕覆盖层 / 答题弹窗 / 跑马灯公告
      • 右侧：弹幕列表 / 聊天输入框 / 预约按钮 / 观看人数热度
      • 下方：课程简介 / 章节列表 / 相关推荐
    • ▼4.5 直播合规要求 最高风险
      • 直播前讲师须签《直播行为规范承诺书》
      • 画面不得出现患者面部/病历信息/设备序列号（需遮挡）
      • AI预审（截图+语音识别）后才可发布回放
      • 管理员实时监播，发现违规立即中断推流
      • 回放上线前人工审核确认
  • ▼五、支付与会员系统
    • ▼5.1 会员体系
      • 免费会员：基础内容（免费科普/试听课/直播预告）
      • 月度/年度会员：畅学全站（按设备绑定走，不按会员）
      • 机构会员：团队管理/数据统计/批量账号
    • ▼5.2 付费购买
      • 单课购买 / 专栏购买（设备码绑定用户可跳过，直接看全课）
      • 微信支付 + 支付宝（0.6%手续费，T+1结算）
      • 课程优惠券 / 邀请码
      • 订单管理 / 退款申请
      • 发票申请（电子/纸质）
  • ▼六、AI智能问答 Phase 5 仅预留接口
    • ▼6.1 RAG知识库问答（技术方案预留）
      • 用户提问 → 语义理解（智谱GLM-4）
      • → 向量检索（QDrant）→ ANN检索 Top-5 chunks
      • → 生成回答（智谱GLM-4）+ 引用来源
      • → 展示回答 + 转人工兜底
    • ▼6.2 知识库构建
      • PDF提取 → 语义分块（500字/chunk）→ embedding → QDrant
      • 先做知识图谱再做RAG，持续优化Chunk策略
    • ▼6.3 接口预留
      • GET /ai/chat — AI问答页面
      • POST /api/ai/ask — 提交问题，返回AI回答
      • GET /api/ai/history — 获取当前用户问答历史
      • GET/POST /api/ai/knowledge — 后台管理知识库内容
    • 6.4 免责声明模板（必须显示）
      • "本回答仅供参考，不能替代专业医疗建议。如有具体诊疗需求，请咨询持牌兽医或医疗专业人员。"

    • 课程TDK自定义（标题/描述/标签）
    • sitemap.xml 生成 → 提交百度/Google

  • ▼十、合规与安全 最高优先级贯穿始终
    • ▼10.1 医疗内容合规红线
      • ❌ 直播出现患者隐私 → ✅ 全部打码或模拟设备教学
      • ❌ AI给出诊断建议 → ✅ 加强免责，限制知识科普范围
      • ❌ 未取得资质推广医疗器械 → ✅ 仅展示设备操作
      • ❌ "治愈率"等绝对化表述 → ✅ 使用"研究显示""通常""可能"措辞
    • ▼10.2 数据安全
      • 全站HTTPS / 密码bcrypt哈希加盐 / 手机号AES-256加密
      • 视频COS私有读+CDN鉴权+Referer限制
      • 连续5次错误锁定30分钟 + 图形验证码 / 短信60秒防刷
      • Access Token 2小时 / Refresh Token 7天
      • Cloudflare WAF（防CC/SQL注入/XSS）
  • ▼十一、第三方服务接入
    • ▼腾讯云全家桶（统一账号，有折扣）
      • VOD（点播视频存储+转码）
      • CSS（直播推流服务）
      • COS（对象存储）
      • SMS（短信通知）
      • CVM（云服务器）
      • MySQL + Redis
    • 微信支付 / 支付宝（0.6%手续费，需企业资质）
    • Cloudflare（CDN + WAF + 免费SSL）
    • 智谱 GLM-4 + QDrant（AI RAG方案）
    • Vercel（Next.js前端部署，免费）

📌 开发优先级与阶段规划

  • P1（Phase 1-2）核心根基：登录注册 + 设备码体系 → 视频点播播放（必须先跑通这两个，其他都是空中楼阁）
  • P2（Phase 3）体验加分：搜索/收藏功能
  • P3（Phase 4）差异化：直播功能（公开直播先上，专业直播后上）
  • P4（Phase 5）AI预留：仅预留接口，不实际接入（省¥2000-5000/月）
  • P5（Phase 6-7）商业闭环：支付接入 + 个人中心 + SEO上线
  • 总工期：4人团队并行 → 10周；单人开发 → 16周以上
  • 最低启动成本：云服务 ¥600-1000/月（不含人力），上线前准备 ¥5,000-20,000
  • 一句话结论：合规是最大变量，设备码是护城河，直播+AI是差异化竞争力
